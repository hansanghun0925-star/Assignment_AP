극한값을 먼저 계산해 g를 다시 쓴다

주어진 극한은 f(x)의 부호에 따라 값이 정해집니다. 부호별로 g(x)를 다시 쓰고 나면, 남는 것은 f의 근이 어떤 모양이냐는 질문뿐입니다. 단계마다 판단할 지점이 하나씩 있습니다.

22.2022학년도 수능 예시문항 · 4점

최고차항의 계수가 1인 삼차함수 f(x)에 대하여 함수

g(x) = f(x−3) × limh→0+ |f(x+h)| − |f(x−h)| h

가 다음 조건을 만족시킬 때, f(5)의 값을 구하시오.

(가) 함수 g(x)는 실수 전체의 집합에서 연속이다.

(나) 방정식 g(x) = 0은 서로 다른 네 실근 α1, α2, α3, α4를 갖고 α1+α2+α3+α4 = 7이다.

1

f(x) ≠ 0인 곳에서 절댓값 벗기기

f는 연속이므로 f(x) > 0이면 그 근방에서도 계속 양수입니다. h가 충분히 작으면 절댓값이 그냥 벗겨집니다.

f(x) > 0인 x에서 g(x)는?

분자에 f(x)를 더하고 빼서 미분계수의 정의 두 개로 나눕니다.

limh→0+ f(x+h) − f(x)h + limh→0+ f(x) − f(x−h)h = f′(x) + f′(x) = 2f′(x)

f(x) < 0이면 근방에서 |f| = −f이므로 부호만 뒤집혀 −2f′(x)가 됩니다.

2

f(a) = 0인 곳에서의 극한값

여기서는 절댓값을 벗길 수 없습니다. 대신 f(a) = 0이라는 사실을 분자에 그대로 써먹습니다.

f(a) = 0일 때 그 극한값은?

f(a) = 0이므로 |f(a+h)| = |f(a+h) − f(a)|. 따라서 h > 0일 때

limh→0+ |f(a+h)|h = limh→0+ | f(a+h) − f(a) |h = |f′(a)|

같은 이유로 |f(a−h)| / h의 극한도 |f′(a)|입니다. 두 값이 같으니 차는 0. 근의 중복도와 상관없이 f의 모든 근에서 극한값은 0이고, 따라서 g(a) = 0입니다.

여기까지의 결론 — g를 다시 쓴 꼴

g(x) = { 2f(x−3)f′(x)   (f(x) > 0) −2f(x−3)f′(x)  (f(x) < 0) 0                    (f(x) = 0)

이제 g는 다항식 두 개와 경계뿐입니다. 절댓값은 더 나오지 않습니다.

3

조건 (가)가 강제하는 것

경계, 즉 f(a) = 0인 점에서만 연속을 따지면 됩니다. 나머지 구간에서는 다항식이라 이미 연속입니다.

f(a)=0인 점 중 g가 불연속일 수 있는 것은?

근 a의 좌우에서 f의 부호가 바뀌면 한쪽 극한은 2f(a−3)f′(a), 다른 쪽은 −2f(a−3)f′(a)입니다. 함숫값은 0이므로

f(a−3) f′(a) = 0

이어야 합니다. 부호가 바뀌는 근에서 f′(a) ≠ 0이면 남는 길은 하나뿐입니다. 반대로 중근이면 f′(a) = 0이라 좌우극한이 모두 0이 되어 저절로 연속입니다. 삼중근도 f′(a)=0이라 같습니다.

(가)의 번역

f의 근 a가 부호가 바뀌는 단순근이면 f(a−3) = 0, 즉 a−3도 f의 근이어야 한다.

근 하나가 자기보다 3 작은 근을 불러옵니다. 왼쪽으로 무한히 갈 수는 없으니 견딜 수 있는 근 구조는 얼마 없습니다.

4

근 구조 네 가지 거르기

삼차함수의 실근 구조는 넷뿐입니다. 하나씩 넣어 봅니다.

(가)와 (나)를 모두 살아남는 구조는?

살아남은 형태

중근을 p, 단순근을 q라 하면 단순근에만 조건이 걸립니다. q−3이 근이어야 하는데 q−3 = q는 불가능하므로 q−3 = p.

f(x) = (x−p)2(x−p−3)

미지수가 p 하나로 줄었습니다. 나머지는 (나)가 정합니다.

5

네 근을 모아 합 맞추기

2단계에서 다시 쓴 g를 그대로 보고 g(x)=0을 풉니다.

g(x) = 0이 되는 x를 모두 모으면?

f(x)=0인 곳은 g(x)=0이고, f(x)≠0인 곳에서는 g(x) = ±2f(x−3)f′(x)이므로 두 인수 중 하나가 0이면 됩니다.

f(x) = (x−p)2(x−p−3)을 전개해 미분하면 f′(x) = 3(x−p)(x−p−2)입니다.

어느 것이 0인가그 해
f(x) = 0x = p,   x = p+3
f(x−3) = 0x = p+3,   x = p+6
f′(x) = 0x = p,   x = p+2
모두 모으면p,  p+2,  p+3,  p+6 — 언제나 서로 다른 네 개

“서로 다른 네 실근”이 저절로 맞는다는 점이 이 형태가 옳았다는 검산입니다. 합을 세웁니다.

4p + 11 = 7  ⟹  p = −1

f(x) = (x+1)2(x−2),   네 근은 −1, 1, 2, 5

예시문항 22번

f(5) = 62 × 3 = 108

되짚기 체크리스트
  • 절댓값이 있는 극한을 부호별로 나눠 미분계수의 정의로 되돌렸는가
  • f의 근에서 극한값이 0임을 f(a)=0을 분자에 끼워 넣어 보였는가
  • 연속 검사를 경계(근)에서만 했는가
  • (가)를 “a가 근이면 a−3도 근”이라는 근끼리의 관계로 바꿨는가
  • 근이 정확히 네 개라는 조건을 검산으로 썼는가

두 조건을 각각 부등식 하나로

(가)는 극솟값의 부호 문제로, (나)는 양 끝 후보값의 크기 비교로 바뀝니다. 남는 일은 격자점 세기뿐입니다. 아래 슬라이더로 두 조건이 언제 켜지는지 직접 확인할 수 있습니다.

함수

f(x) = x3 − 3px2 + q

가 다음 조건을 만족시키도록 하는 25 이하의 두 자연수 p, q의 모든 순서쌍 (p, q)의 개수를 구하시오.

(가) 함수 |f(x)|가 x=a에서 극대 또는 극소가 되도록 하는 모든 실수 a의 개수는 5이다.

(나) 닫힌구간 [−1, 1]에서 |f(x)|의 최댓값과 닫힌구간 [−2, 2]에서 |f(x)|의 최댓값은 같다.

1

극점의 위치를 고정

p가 자연수라는 조건이 그래프 모양을 거의 결정합니다.

f′(x) = 3x(x−2p)입니다. 극댓값과 극솟값은?

p ≥ 1이므로 2p ≥ 2 > 0. 최고차항 계수가 양수인 삼차함수이므로 왼쪽이 극대, 오른쪽이 극소입니다.

f(2p) = 8p3 − 12p3 + q = q − 4p3

여기서 확보한 것

  • 극댓값 f(0) = q > 0 (q가 자연수이므로 항상)
  • f는 [−2, 0]에서 증가, [0, 2]에서 감소 — 2p ≥ 2라 구간 안에 다른 극점이 없습니다
2

(가): 극점 5개의 뜻

|f|의 극점은 두 군데서 생깁니다.

|f|가 극대 또는 극소인 점은 어디서 나옵니까?

f의 극대·극소는 절댓값을 씌워도 그대로 극점으로 남고, x축을 뚫고 지나가는 근에서는 |f|가 0을 찍고 되올라가 극소가 됩니다. 실근 개수로 세어 봅니다.

실근극점 개수조건
서로 다른 3개2 + 3 = 5q − 4p3 < 0
중근 포함 2개3 (근이 극점과 겹침)q − 4p3 = 0
1개2 + 1 = 3q − 4p3 > 0

(가)의 번역

q < 4p3

극댓값이 이미 양수이므로 실근이 셋이려면 극솟값만 음수이면 됩니다. q ≤ 25라서 p ≥ 2이면 4p3 ≥ 32로 저절로 만족됩니다. 실질적으로 p=1만 걸러냅니다.

3

(나): 구간을 넓혀도 안 커진다

[−1,1] ⊂ [−2,2]이므로 최댓값은 넓은 쪽이 항상 크거나 같습니다. 같다는 말은 넓힌 부분이 더 큰 값을 만들지 못했다는 뜻입니다.

[−2,2]에서 |f|의 최댓값 후보 두 개는?

f는 [−2,0]에서 증가, [0,2]에서 감소하므로 최대는 f(0)=q, 최소는 왼쪽 끝 f(−2) = q−12p−8입니다 (f(−2) < f(2)).

좁은 구간에서도 최대는 q, 최소는 f(−1) = q−3p−1. 두 구간의 |f| 최댓값이 같으려면 왼쪽 끝이 −q보다 아래로 내려가지 않으면 됩니다.

12p+8−q ≤ q

(나)의 번역

q ≥ 6p + 4

이때 |f(−1)| ≤ q도 따라오므로 두 구간의 최댓값이 모두 q가 됩니다. 반대로 q < 6p+4이면 |f(−2)|가 좁은 구간의 어떤 값보다도 커져 반드시 어긋납니다.

4

격자점 세기

남은 일은 두 부등식을 동시에 만족하는 자연수 쌍을 세는 것입니다.

6p+4 ≤ q < 4p3, q ≤ 25. p가 가질 수 있는 값은?

p6p+4 ≤ qq < 4p3가능한 q개수
1q ≥ 10q < 4없음0
2q ≥ 16q < 3216 … 2510
3q ≥ 22q < 10822 … 254
≥ 4q ≥ 28—q ≤ 25와 충돌0

칸을 누르면 위 슬라이더가 그 (p, q)로 옮겨 갑니다.

10 + 4 = 14

되짚기 체크리스트
  • p가 자연수라는 조건에서 2p ≥ 2를 끌어내 구간 안 극점 문제를 없앴는가
  • |f|의 극점을 극점 + 부호가 바뀌는 근으로 분해해 셌는가
  • 극점 개수 조건을 극솟값의 부호 하나로 압축했는가
  • 최댓값 조건을 양쪽 후보값의 비교로 바꿔 부등식 하나로 만들었는가
  • 마지막에 q ≤ 25라는 범위를 빠뜨리지 않았는가

두 문항 모두 절댓값이 씌워진 삼차함수를 다루지만 묻는 각도가 다릅니다. 예시문항은 x축을 뚫는 근에서 생기는 부호 뒤집힘을, 9월은 그 근에서 생기는 새 극점과 구간 최댓값을 묻습니다. 같이 놓고 풀면 “절댓값을 씌우면 f의 근에서 새 사건이 생긴다”는 한 문장으로 묶입니다.
